# Жизненный цикл настроек

```text
ОТСУТСТВУЮТ
  ↓ значения по умолчанию
РАБОЧИЕ НАСТРОЙКИ

СОХРАНЕНЫ
  ↓ десериализация
ЗАГРУЖЕНЫ
  ↓ миграция
ТЕКУЩАЯ СХЕМА
  ↓ проверка / нормализация
ДОВЕРЕННЫЕ РАБОЧИЕ НАСТРОЙКИ
```

В пользовательском тестировании некорректные настройки могли приводить к ошибкам, поэтому загрузка понимается не как `JSON → объект → использовать`, а как:

```text
JSON
→ разбор
→ обработка версии схемы
→ проверка / нормализация
→ использование
```

Сохранённые настройки не являются источником истины для Revit; некорректное значение не должно без проверки управлять тяжёлой операцией; отсутствие файла должно давать работоспособные значения по умолчанию; изменение схемы не должно требовать ручного редактирования пользователем.
