# Безопасные значения по умолчанию

Схема настроек v2 закрепила более консервативное поведение для функций, способных создавать постоянную нагрузку или вмешиваться в работу Revit.

```text
auto-refresh      = off
dynamic highlight = off
hotkeys           = off
```

Эти значения отражают опыт реального тестирования: автоматические фоновые операции создавали лишнюю нагрузку, постоянная подсветка плохо масштабировалась на больших наборах, а низкоуровневые горячие клавиши могли конфликтовать с Revit и другими плагинами.

```text
функция существует
!= функция обязана работать по умолчанию
```

Infrastructure хранит и мигрирует эти значения. Ограничение активности во время выполнения принадлежит Application/Revit, а UI управляет пользовательским включением.
