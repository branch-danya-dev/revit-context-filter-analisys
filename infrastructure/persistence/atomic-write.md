# Атомарная запись

`JsonPresetStore` использует `AtomicFileWriter` для сохранения документа пресетов.

Прямое перезаписывание единственного файла создаёт риск частично записанного состояния при сбое процесса или I/O-ошибке.

```text
новый документ
→ сериализовать
→ безопасно записать замену
→ опубликовать завершённый файл
```

Domain не знает о временных файлах или файловой системе; Application не зависит от конкретного протокола записи.

В подтверждениях есть `AtomicFileWriterTests`. При этом переданный анализ не раскрывает точную последовательность файловых операций, поэтому документ фиксирует гарантию и ответственность, а не выдумывает алгоритм.
