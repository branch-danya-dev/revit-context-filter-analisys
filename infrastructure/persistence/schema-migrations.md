# Миграции схем хранения

Сохраняемые документы имеют собственное развитие схемы, независимое от схемы Revit-документа и структуры исходного кода Domain.

## Settings schema v2

Более безопасные значения по умолчанию:

- auto-refresh — off;
- dynamic highlight — off;
- hotkeys — off.

## Preset schema v2

Добавлены `PresetKind`, различие `Full` / `Template` и встроенные шаблоны.

```text
сохранённый документ
→ определить версию схемы
→ преобразовать в поддерживаемое представление
→ проверить / нормализовать где применимо
→ предоставить через порт Application
```

Старая версия схемы не означает автоматически некорректные данные; миграция не должна менять пользовательский смысл без явного правила; версия сохраняемой схемы не равна версии модели Domain.

`PresetDocumentMigrator` и механизм миграции принадлежат Infrastructure, смысл `PresetKind` — Domain.
