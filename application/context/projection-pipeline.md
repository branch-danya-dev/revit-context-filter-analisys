# Цепочка построения проекций контекста

Application строит несколько производных представлений одного контекста кандидатов.

```text
ElementTreeRecord[]
→ BuildContextTreeUseCase
→ дерево Категория / Семейство / Тип

ElementSnapshot[]
→ BuildParameterIndexUseCase
→ каталог параметров

ParameterKey
→ BuildParameterValuesUseCase
→ уникальные значения
```

Дерево отвечает за навигацию, индекс — за доступные параметры, список значений — за доступные значения выбранного параметра, снимки — за данные для вычисления условий.

Производная проекция не становится источником истины. После изменения исходного контекста старые дерево, индекс и значения не считаются автоматически актуальными.
