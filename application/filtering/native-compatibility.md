# Совместимость со штатным фильтром Revit

`NativeFilterCompatibilityAnalyzer` отвечает на отдельный вопрос:

> можно ли текущий `FilterDefinition` представить как штатный Revit `ElementFilter`?

Это не часть обычного клиентского вычисления.

Подтверждённый совместимый набор операторов: `Equals`, `NotEquals`, `GreaterThan`, `GreaterThanOrEqual`, `LessThan`, `LessThanOrEqual`, `InList`.

Ограничения включают `Negate`, ряд строковых операторов, `Between`, большинство вычисляемых параметров и верхнеуровневый OR.

```text
фильтр корректен в ContextFilter
!=
фильтр представим штатными средствами Revit
```

Анализ совместимости не должен обеднять основной язык фильтра. При несовместимости недоступно только конкретное действие создания штатного фильтра.
