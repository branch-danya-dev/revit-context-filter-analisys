# Контекст системы

## Назначение

ContextFilter — плагин Autodesk Revit 2025 для быстрого построения контекстной выборки элементов, формирования условий фильтрации и применения результата к Revit.

Система работает внутри уже запущенного Revit и не является самостоятельным редактором BIM-данных.

## Участники и внешняя среда

```text
BIM-специалист / проектировщик
        ↓
ContextFilter
        ↓
Autodesk Revit 2025
        ↓
Документ / виды / элементы / выделение
```

## Что система получает от Revit

- текущий документ;
- активный вид;
- текущее выделение;
- элементы и их Category / Family / Type;
- параметры экземпляров и типов;
- сведения для вычисляемых свойств Category, Family, Level, Workset и других.

## Что система создаёт сама

- `ElementSnapshot`;
- `ParameterKey`;
- `FilterDefinition`;
- `FilterResult`;
- `PresetDefinition`;
- индексы параметров и производный кэш;
- состояние интерфейса.

Эти представления помогают анализировать данные Revit, но не становятся источником истины для BIM-модели.

## Что система возвращает в Revit

После вычисления результата плагин может изменить выделение, временно скрыть/изолировать элементы, выполнить инверсионную изоляцию, сбросить временную видимость или при совместимости создать `ParameterFilterElement`.

> **ContextFilter интерпретирует и использует состояние Revit, но не присваивает себе владение BIM-моделью.**
