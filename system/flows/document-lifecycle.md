# Жизненный цикл документа

ContextFilter работает с производным состоянием, построенным из конкретного Revit-документа. Изменение исходного контекста должно переоткрывать зависимые данные.

## DocumentChanged

```text
DocumentChanged
→ задержка объединения частых событий
→ оценка масштаба изменения
→ локальное обновление, если оно безопасно
   ИЛИ
→ пометить данные устаревшими / сбросить и пересобрать
```

## Смена активного вида
Для `ActiveView` меняется область кандидатов, поэтому зависимые дерево, индекс параметров, значения и результат фильтра требуют пересмотра.

## Смена выделения
Для `CurrentSelection` выделение является частью идентичности рабочего контекста. Старый контекст после смены выделения больше не актуален.

## Закрытие или смена документа

- работа, привязанная к старому документу, останавливается;
- старый контекст перестаёт использоваться;
- состояние интерфейса старого документа сбрасывается;
- события Revit не должны запускать тяжёлую обработку для уже неактуального документа.

## Активность пользовательской сессии

Когда пользовательская сессия ContextFilter неактивна, `Idling` не должен выполнять тяжёлый сбор, построение индексов или динамическое выделение.

```text
панель закрыта / сессия неактивна
→ нет тяжёлой фоновой работы
```
