# Повторное использование пресета

Пресет позволяет сохранить условия фильтра и применить их позже.

## Сохранение

```text
текущее состояние фильтра
→ BuildPresetUseCase
→ PresetDefinition
→ хранилище пресетов
→ presets.json
```

Поддерживаются `Full` и `Template`: первый сохраняет конкретные значения, второй — структуру условий без жёсткой привязки к значениям.

## Повторное применение

```text
сохранённый PresetDefinition
→ загрузить
→ восстановить условия фильтра
→ разрешить их в текущем контексте
→ вычислить заново
→ новый FilterResult
```

Пресет не хранит «вечный» результат фильтрации.

```text
сохранённые условия
!= текущее состояние документа
!= текущий найденный набор
```

Ошибка загрузки пресетов должна быть видима пользователю и не маскироваться под корректное отсутствие сохранённых данных.
