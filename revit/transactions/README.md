# Транзакции Revit

`transactions/` описывает границу записи в Autodesk Revit.

Не каждая операция ContextFilter изменяет состояние модели/вида и не все операции Revit имеют одинаковые требования к транзакциям. Поэтому транзакция не является глобальной оболочкой всего сценария фильтрации.

```text
чтение / вычисление
→ нет причины открывать транзакцию записи

изменение среды, требующее транзакции Revit
→ выполнить в корректном транзакционном контексте
```

Клиентское вычисление фильтра на `ElementSnapshot` не требует транзакции Revit.

- [`transaction-boundary.md`](transaction-boundary.md)

Во время пользовательского тестирования изоляция выполнялась вне требуемого транзакционного контекста и вызывала ошибку. Это подтвердило, что корректность транзакции — ответственность адаптера Revit.

> Корректность Domain/Application не освобождает адаптер Revit от соблюдения контракта изменения среды.
