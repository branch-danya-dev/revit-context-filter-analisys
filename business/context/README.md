# Business Context

Этот раздел отвечает на вопрос:

> **Почему появился ContextFilter и в каком пользовательском контексте он должен приносить пользу?**

## Канонический документ

- [`product-context.md`](product-context.md) — исходная проблема, пользователи, участники, развитие запроса, продуктовая цель и фактический outcome.

## Коротко

В Revit пользователю часто нужно быстро найти элементы «здесь и сейчас» и сразу применить к найденному набору рабочее действие.

Исходный ручной путь требовал найти подходящий элемент / вид, выбрать похожие экземпляры и затем продолжить работу со selection или visibility.

ContextFilter сокращает этот путь:

```text
current Revit context
→ filter intent
→ precise matched set
→ useful action
```

## Участники

- заказчик — заместитель директора проектного института;
- предметный эксперт — BIM-координатор;
- исполнитель — System Analyst · Solution Designer · Developer;
- финальную приёмку проводил директор проектного института.

Название организации публично не раскрывается.
