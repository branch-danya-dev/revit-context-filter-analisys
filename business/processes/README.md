# Пользовательские процессы

Этот раздел описывает ContextFilter как пользовательский сценарий, не раскрывая внутреннюю координацию Application.

## Основной сценарий

- [`main-user-journey.md`](main-user-journey.md) — полный путь от рабочего контекста Revit до действия над найденным набором;
- [`diagrams/main-user-flow.puml`](diagrams/main-user-flow.puml) — визуальный сценарий.

Коротко:

```text
Работа в Revit
→ выбрать область поиска
→ открыть ContextFilter
→ Категория / Семейство / Тип
→ параметр + значение
→ найденный набор
→ действие
→ продолжить работу в Revit
```

Альтернативный путь начинается с предварительного выделения и ограничивает дальнейшую фильтрацию этим набором.

Сохранение пресета или шаблона является дополнительным шагом повторного использования условий фильтра, а не обязательной частью каждого сценария.

Техническая координация этих действий принадлежит [`../../application/`](../../application/).
