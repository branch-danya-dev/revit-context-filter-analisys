# Логическая композиция

Язык фильтра построен как дерево `IFilterNode` из `FilterGroup` и `FilterCondition`.

`FilterGroup` содержит `Id`, `LogicalOperator: And | Or`, `Negate`, `IsEnabled`, `Children`. Группа может содержать другие группы и условия.

`FilterCondition` содержит `ParameterKey`, `Operator`, `Operands`, `IgnoreCase` и является атомарным утверждением над одним фильтруемым свойством.

## AND
Группа `And` требует совместного выполнения дочерних условий согласно контракту вычислителя.

## OR
Группа `Or` выражает альтернативные ветви условий.

## Negate
`Negate` меняет смысл узла как целого логического выражения, а не механически заменяет каждый дочерний оператор обратным.

## IsEnabled
Domain явно хранит признак активности узла. Переданный анализ не фиксирует полную таблицу истинности для пограничных случаев пустой группы или группы, где все дочерние узлы отключены. Эти детали не придумываются без проверки исходного кода или тестов.

```text
логическое дерево
!= плоский список условий
```

Оптимизация допустима только при сохранении эквивалентной логической семантики.
