# Дерево контекста

Для навигации множество кандидатов представлено иерархией:

```text
Категория
└─ Семейство
   └─ Тип
```

Типы узлов задаются `ContextNodeType`: `Category`, `Family`, `Type`.

Каждый `ContextNode` содержит подтверждённые сведения `ElementIds`, `TotalCount`, `IsChecked`, `DisplayName`, `Key`.

```text
Категория → Семейство → Тип
!=
иерархия владения Revit
```

Это производная навигационная проекция над кандидатами. Она не утверждает, что Category владеет Family или Type.

## Инварианты

1. Узел представляет подмножество кандидатов.
2. Отметка узла влияет на дальнейшее построение фильтра, но не меняет исходную модель.
3. `DisplayName` не заменяет стабильный ключ там, где нужна идентичность.
4. `TotalCount` — производное количество.
5. Визуальная группировка не меняет фактическое множество элементов.
