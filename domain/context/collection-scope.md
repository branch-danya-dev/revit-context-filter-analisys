# Область сбора

`CollectionScope` определяет **семантическую границу множества кандидатов**, внутри которой пользователь формулирует фильтр.

Поддерживаются:

```text
ActiveView
EntireDocument
CurrentSelection
```

## ActiveView
Кандидаты ограничены элементами текущего активного вида.

## EntireDocument
Кандидаты относятся ко всему текущему Revit-документу. Предупреждения о размере модели и способ сбора не являются частью семантики этого значения.

## CurrentSelection
Кандидаты ограничены текущим пользовательским выделением. Уже сформированный вручную набор используется как входная область дальнейшей фильтрации.

## Инварианты

1. `CollectionScope` определяет область поиска, а не условие фильтра.
2. Один `FilterDefinition` в разных областях может давать разные результаты.
3. `CurrentSelection` не расширяется до всех совпадающих элементов документа.
4. Изменение области требует повторного получения соответствующего набора кандидатов.
5. Политика производительности не должна менять смысл области.

`CollectionScope` входит в `FilterDefinition`, `CollectedContext` и `PresetDefinition`, поэтому фильтр явно сохраняет, **где** он должен применяться.
